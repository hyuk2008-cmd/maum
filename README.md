# 마음 커넥트 (Ma-eum Connect)

LA 한인 커뮤니티 단톡방에 수년간 쌓인 업체 추천을 검색 가능한 신뢰 기반
업체 디렉토리로 정리하는 웹 포탈입니다.

## 왜

한인 이민사회 단톡방에는 "이 업체 믿고 다녀도 돼요" 식의 실사용 후기와
추천이 수년간 쌓여있지만, 그 정보는 대화방 안에 파묻혀 있어 매번 다시
물어봐야 합니다. 이 프로젝트는 그 대화 아카이브를 구조화된 데이터로
변환해, 검색·열람 가능한 업체 디렉토리로 만듭니다.

## 현재 구현된 것 (MVP)

- **KakaoTalk 대화 파서** (`lib/parser/kakaoParser.ts`) — 카카오톡
  "대화 내보내기" `.txt` 포맷을 파싱해 날짜/발신자/본문으로 구조화합니다.
  줄바꿈이 포함된 멀티라인 메시지도 처리합니다.
- **업체 추출 파이프라인** (`lib/parser/extractBusinesses.ts`) — 룰 기반
  휴리스틱으로 전화번호가 포함된 홍보/추천성 메시지를 찾아 전화번호를
  기준으로 동일 업체 언급을 클러스터링하고, 카테고리를 키워드로 분류하며,
  최근성 + 언급 횟수 기반 신뢰도 점수(`trustScore`)를 계산합니다.
- **발신자 익명화** (`lib/parser/anonymize.ts`) — 실명은 절대 저장하지
  않고, salt를 사용한 단방향 해시로 `member_xxxxxxxx` 형태의 가명 ID만
  남깁니다.
- **웹 UI** — 업체 검색/카테고리 필터 홈(`app/page.tsx`)과 업체
  상세페이지(`app/business/[id]/page.tsx`)에서 신뢰도, 최근 언급 시점,
  커뮤니티 언급 근거(발췌)를 확인할 수 있습니다.
- **중복 게시 통합** — 같은 광고/추천 메시지가 여러 번 반복 게시된 경우
  하나의 언급으로 합치고 "N회 게시" 배지로 표시합니다
  (`lib/parser/extractBusinesses.ts`의 `dedupeKey`).
- **전단지 사진 반영** — 단톡방에 올라온 업체 전단지 이미지도 (Google
  Drive의 이미지 OCR/설명 텍스트를 통해) 같은 파이프라인으로 처리해
  "📷 전단지" 출처로 구분 표시합니다.
- **주소 추출 + 별점 표시** — 광고 텍스트에서 미국 주소 패턴을 인식해
  업체 카드에 표시하고, 애매한 0-100 신뢰도 점수는 5점 만점 별점으로
  변환해 보여줍니다 (`lib/stars.ts`).
- **깨진 텍스트 정리** — 이모지가 잘못 디코딩되며 생긴 깨진 문자,
  구글 드라이브가 자동으로 붙이는 "Image labels" 메타데이터, 이스케이프
  문자를 정제합니다 (`extractBusinesses.ts`의 `cleanText`).
- **후기 작성** (`components/ReviewSection.tsx`) — 업체 상세 페이지 하단에서
  별점 + 후기를 남길 수 있습니다. 아직 DB가 없어 지금은 브라우저
  localStorage에만 저장되는 체험판입니다.
- **실제 전단지 이미지 표시** (`components/DriveImage.tsx`) — 업체 카드와
  "업체 소개" 항목에 원본 전단지 사진을 Google Drive 썸네일로 보여줍니다.
  이미지가 없거나 공유 권한이 없어 못 불러오면 자동으로 숨겨집니다.
- **홈 화면 히어로 배너** (`components/HeroCarousel.tsx`) — `public/hero/`에
  넣은 이미지를 자동으로 슬라이드 전환하며 보여줍니다.
- **카테고리 아이콘** (`lib/categoryIcons.ts`) — 실제 사진이 없는 업체는
  카테고리에 맞는 아이콘(자동차🚗, 병원🏥, 부동산🏠 등)을 색상 배경과
  함께 대신 보여줘 목록이 한눈에 구분되도록 했습니다.

현재 `data/seed.json`은 실제 카톡 대화 아카이브 + 전단지 이미지 일부를
위 파이프라인으로 처리해 만든 **익명화된 파생 데이터**입니다. 원본
대화/이미지 파일은 절대 리포지토리에 커밋하지 않습니다 (`.gitignore` 참고).

## 대화 파일 처리하기

```bash
# ANONYMIZE_SALT는 커밋하지 않는 비밀값으로 지정하세요
# photos.json은 선택 사항: [{ id, title, text, createdTime }][] 형태의
# OCR/설명 텍스트 배열 (전단지 사진을 함께 반영하고 싶을 때)
ANONYMIZE_SALT="$(openssl rand -hex 16)" npx tsx scripts/build-seed.ts /path/to/KakaoTalkChats.txt [/path/to/photos.json]
```

`data/seed.json`이 새로 생성됩니다.

## 알려진 한계 (다음 단계)

- **업체명/카테고리 추출은 현재 룰 기반**입니다. 인사말 등을 걸러내는
  휴리스틱을 적용했지만, 정확도를 높이려면 LLM 기반 추출(업체명, 주소,
  추천/비추천 판단, 중복 업체명 정규화)로 교체가 필요합니다.
- **DB 미연동**: 지금은 정적 JSON 시드 데이터를 사용합니다. 후기도
  localStorage 임시 저장이라 브라우저/기기 간 공유되지 않습니다. 다음
  단계는 PostgreSQL(Supabase 권장) 연동, 사용자 인증(구글/네이버/카카오/
  애플/이메일), 후기 영구 저장, 사업자 클레임(claim) 플로우입니다.
- **전단지 이미지는 샘플만 반영**: 폴더당 수백 장 중 대표 샘플(약 500장)만
  처리했습니다. 전체를 반영하려면 `scripts/build-seed.ts`에 전체 목록을
  다시 넣어 재생성하면 됩니다.
